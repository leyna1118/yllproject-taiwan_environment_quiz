# 你是哪種護島人？ — 台灣環保性向測驗

第六屆堉璘臺大人才培育計畫，「Travel Green」企劃轉向後的新方向：把「離島旅遊資源難被觸及」的洞察，延伸成一個 2 分鐘、像 MBTI 一樣好玩的線上測驗，幫使用者找到自己最在乎的台灣環境議題，並直接導向真實存在的組織、行動與資源。

**團隊**：徐薪淳、陳奕瑄

## 這是什麼

一個純前端、零後端的靜態網頁測驗，玩法參考 [types.tw](https://types.tw/)（MBTI 式選擇題計分）與 [pr97](https://chiaying1230.github.io/pr97-gifted-myth/)（情境式選擇的語感），10 題情境選擇題，結果分成四種「護島人格」：

| 類型 | 議題面向 |
|---|---|
| 🌊 護海潮人 | 海洋與海廢 |
| 🌲 山野守望者 | 山林與生物多樣性 |
| ☀️ 未來行動派 | 氣候與能源行動 |
| ♻️ 日常實踐家 | 循環經濟與永續生活 |

結果頁除了主要人格類型，還會顯示四項「護島指數」（每個議題面向的關注程度百分比），並附上該類型對應的真實台灣環保組織連結，以及一個「好玩小任務」。

```
yllproject-taiwan_environment_quiz/
```

## 本機預覽

直接用瀏覽器打開 `index.html` 即可，不需要安裝任何套件、不需要跑 server。

```
open index.html          # macOS
# 或直接把檔案拖進瀏覽器
```

> 部分瀏覽器 API（分享連結、複製到剪貼簿）在 `file://` 本機開啟或沙盒預覽環境下可能被限制，程式已經做了保底處理：分享按鈕一定會顯示一個可以手動選取複製的連結欄位，不會整個沒反應。真正上線（部署到 GitHub Pages / 任何 https 網域）後，分享功能會用瀏覽器原生分享或自動複製到剪貼簿。

## 部署到 GitHub Pages

1. 把這個資料夾 push 到一個 GitHub repo（例如 `yllproject-taiwan_environment_quiz`）。
2. Repo 設定 → Pages → Source 選 `main` branch、`/ (root)` 資料夾。
3. 因為入口檔案已經叫 `index.html`，GitHub Pages 會自動把它當首頁，網址大概會是：
   `https://<你的帳號>.github.io/yllproject-taiwan_environment_quiz/`

## 如何新增題目

打開 `index.html`，找到 `QUESTIONS` 這個陣列（有註解標示），在最後面加一組：

```js
{
  text: "題目文字⋯",
  options: [
    { label: "選項一", type: "ocean" },
    { label: "選項二", type: "forest" },
    { label: "選項三", type: "climate" },
    { label: "選項四", type: "circular" }
  ]
}
```

`type` 只能是 `ocean` / `forest` / `climate` / `circular` 四種之一，順序不用固定，但建議每題四個選項各對應一個不同類別，計分邏輯才會平衡。加完不用改任何其他程式碼。

## 如何新增 / 調整推薦組織

找到 `RESULT_TYPES` 這個物件，四個類型（`ocean` / `forest` / `climate` / `circular`）各自有一個 `resources` 陣列，加一筆：

```js
{ name: "組織名稱", url: "https://...", desc: "一句話介紹" }
```

> 正式對外發布前，建議先跟被列進去的組織確認一下是否 ok 被列為推薦資源，尤其如果之後想談合作導流。

## 計分邏輯

每題被選中的類別 +4 分，其餘三個類別各 +1 分，10 題加總後換算成四個類別的百分比，最高分的類別就是主要結果類型（同分時以最後一題的選擇決勝）。這個「主要傾向 +1 分陪襯」的算法讓四個「護島指數」不會只是死板的「答對幾題」百分比，更接近一般線上性格測驗的手感。
